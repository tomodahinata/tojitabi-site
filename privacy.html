とじたび プライバシーポリシー

制定日：2026年11月18日

運営者：友田陽大

「とじたび」（以下「本アプリ」）が扱う情報と、その扱い方を説明します。

1. 旅程の内容は端末内に保存します

  • 入力した旅程（タイトル、日程、予定、時刻、場所、メモ、持ち物）は、iPhone の中の本アプリの領域にだけ保存します。運営者のサーバーはありません。
  • 旅程の内容は、下の分析やクラッシュ報告を許可した場合でも送信しません。ファイル名や自由入力の文字も同じです。
  • iOS の端末バックアップ（iCloud バックアップやパソコンへのバックアップ）を使っている場合、iOS の仕組みにより、他のアプリのデータと同じく本アプリのデータもそのバックアップに含まれます。本アプリが送るものではありません。

2. アカウントはありません

登録やログインはありません。氏名、メールアドレス、電話番号を求めません。

3. 許可した場合にだけ送る情報

本アプリは 2 つのサービスを使います。どちらも最初はオフで、利用者が許可するまで、本アプリはそれらの機能を起動せず、通信もしません。許可はサービスごとのスイッチで行い、スイッチは設定の「分析とエラー報告」にある「利用状況の分析」と「クラッシュとエラーの報告」の 2 つです。初めて PDF または画像の書き出しに成功した後のプレビューで、「A4 一覧」か「日ごとの画像」を表示しているあいだ、その下に案内を表示します（「冊子」の表示中は表示しません）。案内には同じ 2 つのスイッチ（どちらもオフ）と、この方針へのリンク、「閉じる」があります。案内は 1 回のプレビューのあいだだけで、「閉じる」を押すかプレビューを離れると、二度と表示しません。すでに設定でどちらかをオンにしているときは、案内を表示しません。許可しなくても、本アプリの機能に違いはありません。設定でいつでも変えられます。

3.1 利用状況の分析（PostHog）

項目内容
送るもの操作の種類（例：旅程を作成した、PDF を書き出した）と、その区分値（例：日数「4-7」、予定の数「6-10」）。ビルドの種類（environment：debug または release）。端末で作る匿名 ID（UUID）。イベントの時刻と ID
送らないもの旅程の内容、機種・OS・言語・タイムゾーン・画面サイズなどの端末情報、位置情報、広告 ID
送り先PostHog（米国のサーバー、us.i.posthog.com）
時機20 件たまったとき、約 30 秒ごと、本アプリが裏に回ったとき。未送信の分は端末に最大 200 件まで置き、古い順に捨てます
サーバー側の設定人物プロファイルを作らない、IP アドレスから位置を推定しない、IP アドレスを匿名化する
目的本アプリの改善（どの機能が使われ、どこで書き出しに失敗するかを知るため）

3.2 クラッシュとエラーの報告（Sentry）

項目内容
送るもの例外の種類、異常終了の種類（シグナルの番号、Mach 例外の定数など）、プログラム上の位置（関数名、プログラムの部品の名前、メモリ上のアドレス）、スレッドの一覧（番号、異常が起きたスレッド・報告を作ったスレッド・メインのスレッドの区別、それぞれのプログラム上の位置。スレッドの名前は消します）、記号化（クラッシュの位置を関数名に戻す処理）に使う部品の識別子（ビルドごとの UUID）・読み込みアドレス・サイズ、本アプリのリリースの値（バンドル ID、版、ビルド番号）、ビルドの種類（debug または release）、OS の名前・版・ビルド番号、端末のモデル名、本アプリが定めたエラーの種類とコード（例：「書き出し・空き容量不足」）、報告の ID・時刻・重大度、Sentry の SDK の名前と版、接続元の IP アドレスを利用者の情報に入れないという指定
送らないもの旅程の内容、エラーの説明文、操作の履歴、ファイルの場所（パス）、画面の画像、利用者の情報
送り先Sentry（米国のサーバー、ingest.us.sentry.io）
時機エラーはその場で、クラッシュは次に起動したとき
サーバー側の設定本アプリは、接続元の IP アドレスを利用者の情報に入れないよう指定して送ります。ただし、IP アドレスから推定される位置（国・地域・市区町村）が Sentry に保存されることがあります
目的不具合の発見と修正

3.3 送らないもの（どちらのサービスでも）

広告 ID（IDFA）、位置情報、連絡先、写真。本アプリはトラッキング（他社のアプリやウェブサイトをまたいだ追跡）を行いません。

4. 許可の取り消しと、その限界

  • 設定の 2 つのスイッチ（「利用状況の分析」と「クラッシュとエラーの報告」）で、サービスごとにいつでも取り消せます。
  • 取り消すと、本アプリはそのサービスの通信を止め、端末内に残っている未送信のデータと、そのサービスが端末に作ったファイル（匿名 ID を含む）を消します。途中で本アプリが終了した場合は、次の起動時にそのサービスを起動する前に消し直します。
  • 取り消せないもの: 取り消した時点ですでに通信中だったデータは止められません。サーバーに届いたデータは、端末から消すことはできません。
  • 匿名 ID は本人の氏名などと結び付いていないため、運営者がサーバー上のデータを特定の人のものとして見つけられない場合があります。
  • 同じ起動中に取り消してから再び許可した場合は、次の起動から有効になります。そのとき匿名 ID は新しくなります。
  • 各サービスでのデータの保存期間は、運営者が各サービスで設定した期間に従います。期間を過ぎたデータは、そのサービスが削除します。

5. 購入

冊子機能の購入は Apple の App Store が処理します。本アプリと運営者は、支払い方法やカードの情報を受け取りません。本アプリは Apple から購入の確認結果を受け取り、確認した日時を端末内に保存します。冊子機能は、端末の StoreKit（App Store の購入を端末で管理する Apple の仕組み）が購入の記録を示している間使えます。保存した日時を使うのは、StoreKit が購入の記録を示しているのに、その確認（署名の検証）が一時的にできない場合だけです。そのときに限り、最後に確認した日時から 30 日まで冊子機能を使えるようにします。

6. 共有とバックアップ

PDF や画像を共有したり、バックアップのファイルを書き出したりするのは、本人が操作した場合だけです。共有した先（メール、メッセージ、クラウドなど）での扱いは、その先のサービスの方針に従います。共有の画面で「画像を保存」を選ぶと、iOS が写真への追加の許可を尋ねます。本アプリは写真への追加だけを使い、写真を読み取りません。

7. 端末内に保存するもの

  • 旅程のデータ
  • 書き出した PDF と画像の一時ファイル（次の書き出しや次の起動で消します）
  • 分析とクラッシュ報告の許可の記録
  • 購入を確認した日時
  • この端末で新しく作った旅程の数（1 つの数字。分析を許可している場合に、「何本目か」の区分として旅程の作成のイベントに付けます。旅程の内容は含みません）
  • App Store の評価をお願いした版と、印刷や共有を終えた回数（評価をお願いする時機を決めるためだけに使います。端末の外へ送らず、旅程の内容は含みません）
  • 冊子の設定の「裏表紙にアプリの名前を入れる」を選んでいるか（オンかオフか。端末の外へ送りません）
  • 設定の「共有するときにアプリの紹介を添える」を選んでいるか（オンかオフか。端末の外へ送りません）
  • 冊子の設定の「片面ずつ刷る」を選んでいるかと、片面ずつ刷るときの紙の入れ直し方（紙を入れる場所、紙の向き、裏の順番と向き）。端末の外へ送りません。分析を許可している場合に印刷の操作に付ける区分（自動両面か、片面ずつの 1 回目か 2 回目か、片面の A4 一覧か）は、この設定ではなく、そのとき刷ったものから決めます
  • 「サンプルの旅程で試す」で作った旅程の識別子（どの旅程がサンプルかを示すためだけのものです。分析を許可している場合に、プレビュー（書き出し、印刷、共有を含む）や購入の画面の操作に「サンプルか自分の旅程か」の区分として付けます。識別子そのものと旅程の内容は送りません）
  • 許可したサービスが作るファイル（許可を取り消すと消します）

本アプリを削除すると、これらは iOS により端末から消えます。
